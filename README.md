# 再提出を含む提出日シナリオ比較

必要日から製作・審査・修正の日数を逆算し、再提出を0・1・2回と仮定した提出日を比較する、無料の小さなブラウザーツールです。

**[ブラウザーで試す](https://hitocase.itch.io/resubmission-schedule)** → 「Run tool」→「合成例を入れて試す」。試用や比較票の取得に登録・支払いは不要です。

工程を1本ずつ見積もる担当者と、既存の工程表への組み込みを検討する実装担当者向けです。実案件での便益・有料需要は未検証です。

## 比較できる条件

- 再提出0・1・2回の、所要日数・提出日・基準日からの余裕
- 暦日、または月〜金と指定した除外日
- 複数審査の並列（最大値）／直列（合計）
- 空欄の「未確定」と、明示した0日
- 選択してコピーできる比較票・合成3案件のCSV見本

所要日数は「製作＋初回審査＋再提出回数×（修正＋再審査）」です。必要日を数えず、前日から逆算します。余裕は暦日です。祝日は自動取得しません。

合成例：必要日2026-11-30、製作10日、初回審査5日、修正3日、再審査5日を暦日で計算すると、提出日は0回で11月15日、1回で11月7日、2回で10月30日です。実顧客のデータや受注実績ではありません。

## ローカルで確認する

このフォルダーには、画面・スタイル・計算コア・合成CSVが揃っています。外部API、APIキー、ビルドや追加パッケージは使いません。

Pythonが既にある環境では、このフォルダーをカレントディレクトリとして次を実行し、`http://127.0.0.1:8000/`を開けます。

```text
python -m http.server 8000 --bind 127.0.0.1
```

確認後はCtrl+Cで停止します。既存の静的HTMLプレビュー環境でも確認できます。

| ファイル | 内容 |
|---|---|
| index.html / app.js / style.css | 条件入力・結果比較・コピー表示 |
| business.js | 計算コア。今回の試用では提出日比較だけを呼びます |
| sample-comparison.csv | 画面内にも表示する合成3案件の見本 |
| README.txt | 無料利用の前提と提供範囲 |

## 対象外とデータ

法定期限・契約適合・実納期を保証せず、再提出の発生確率も予測しません。実システムへの接続・提出や工程全体の最適化は行いません。担当者による確認と併せて使ってください。

ツールの入力はブラウザー内だけで処理し、ツールから外部送信・解析・自動保存しません。合成・匿名化データで試してください。氏名・顧客名・案件名・秘密情報を入力せず、Issueやコメントにも投稿しないでください。入力はページの再読込・終了で消えます。

## 複数案件の一覧・CSV整形が必要な場合

無料版は1工程の比較を完結できます。複数案件をまとめた提出日一覧や、お使いの表の列名に合わせたCSV出力が必要な場合は、[配布ページ](https://hitocase.itch.io/resubmission-schedule)のコメント欄で、有料の追加作業の見積もりを依頼できます。

希望する入力列・出力列・おおよその件数を、公開して差し支えない範囲でお知らせください。秘密資料や連絡先は不要です。コメント投稿にはitch.ioへのログインが必要です。範囲・料金・納期・対応可否は運営者が個別に確認し、投稿だけで契約・決済は成立しません。無料利用に相談や購入は必要ありません。

GitHubを使う方は、[複数案件の一覧・CSV整形の公開相談](https://github.com/chamcham5/resubmission-schedule/issues/new/choose)からも同じ概要を記入できます。投稿にはGitHubへのログインが必要です。
